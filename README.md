# WEB-dev

Статический редактор HTML/CSS/JS. Запуск из корня репозитория:

```sh
python3 -m http.server 8000 --bind 127.0.0.1 --directory .
```

Сервер должен отдавать весь репозиторий, включая `preview-runner.js` и `vendor/`.
Установка пакетов и сборка для работы приложения не нужны.

## Выполнение JavaScript

Пользовательский JS выполняется в отдельном Web Worker. WorkerDOM передаёт
изменения виртуального DOM в iframe, в котором выполнение скриптов запрещено.
Код вкладки JS, встроенные HTML-скрипты и HTML-обработчики событий выполняются
только в Worker. Никакой `eval` пользовательского кода в потоке редактора нет.

Редактор проверяет ответ Worker каждые 100 мс. Если Worker перестал отвечать
примерно на 1,2 секунды, редактор вызывает `terminate()` и сообщает об ошибке.
Проверка находится снаружи Worker: бесконечный цикл, заблокированный таймер,
бесконечная цепочка микрозадач или тяжёлая нативная операция не мешают остановке.
«Стоп» немедленно завершает Worker, «Запуск» создаёт новый. Размеры сообщений,
число узлов и объём изменений DOM ограничены перед передачей в рендеринг.

При открытии страницы, обновлении и импорте JSON восстанавливается исходный код
и статический HTML/CSS, но **JavaScript автоматически не запускается**.
Запуск — кнопкой «Запуск» или Ctrl/Cmd+Enter. Поэтому сохранённый ошибочный код
можно исправить без очистки localStorage. Остановка и ошибка исходный код
не удаляют. Запись в хранилище редактора из Worker отключена.

## Совместимость

Нужен современный браузер с Web Workers и HTTP(S)-сервер. WorkerDOM 0.36.0
хранится локально вместе с лицензией, сеть для выполнения не нужна.
Внешний CodeMirror отвечает только за редакторы; без CDN используются textarea.

WorkerDOM реализует часть DOM: базовые селекторы, создание и изменение элементов,
стили, события и значения полей. Это не полный объект `window` браузера.
Внешние HTML-скрипты, модули, вложенные iframe и плагины не поддерживаются.
DOM-обновления асинхронны; библиотеки, которым необходимы неподдерживаемые DOM API
или синхронные измерения layout, могут потребовать адаптации. Изоляция потока
защищает от зависающих вычислений; это не серверная песочница с жёсткой квотой
памяти для намеренно вредоносного кода.

## Проверки

При запущенном сервере, установленных Playwright и Chromium:

```sh
node tests/preview.test.cjs
```

Путь к Chromium задаётся через `CHROMIUM_PATH`. Проверки взаимодействуют с
редактором **во время зависания**, до срабатывания watchdog. Также проверяются
обновления с ошибочным кодом в localStorage, таймеры, микрозадачи, `eval`, тяжёлое
регулярное выражение, рекурсия, HTML-скрипты и обработчики, работа DOM/CSS,
ограничения консоли и DOM, изоляция событий, «Стоп», повторный запуск и импорт.
